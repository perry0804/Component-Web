references/

## 使用约定

- **inbox.md 只追加不整理**：随手记，保持低成本；整理成组件后把条目勾选为 `- [x]` 并附上组件路径。
- **大文件注意**：录屏尽量转成压缩过的 GIF / WebM，单个文件建议 < 5 MB，避免仓库膨胀。
